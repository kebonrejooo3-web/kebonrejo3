# Website Profil Resmi & WebGIS Dusun Kebonrejo 3

Website resmi Profil dan WebGIS Interaktif Dusun Kebonrejo 3, Desa Kebonrejo, Kecamatan Candimulyo, Kabupaten Magelang.

## Fitur Utama
1. **Profil Resmi Dusun**: Informasi wilayah, sejarah singkat, data demografi penduduk, dan struktur tata pamong/pemerintahan dusun.
2. **WebGIS Interaktif**: Pemetaan spasial digital batas wilayah RT (RT 01 – RT 04), titik lokasi fasilitas umum, tempat ibadah, pendidikan, jasa, dan potensi UMKM warga.
3. **Dokumentasi & Galeri**: Dokumentasi resmi kegiatan masyarakat dan program kerja KKN.
4. **Desain Modern & Responsif**: Tampilan modern, ringan, transisi header transparan, full viewport hero section, dan 100% responsif di desktop, tablet, dan smartphone.

## Teknologi Utama
*   **HTML5, CSS3 (Vanilla), JavaScript Native (ES6)**
*   **Leaflet.js** & GeoJSON Spasial Data
*   **FontAwesome 6**
*   **Static Web Architecture (Zero Backend / Serverless)**

## Lisensi & Pengembangan
Dikembangkan sebagai luaran program Kuliah Kerja Nyata (KKN) Dusun Kebonrejo 3.
